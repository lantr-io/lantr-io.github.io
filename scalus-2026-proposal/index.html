One stack, four pillars

What Scalus delivers

One coherent platform across the full application journey — smart contracts, runtime, chain access, and L2 scaling.

Smart contracts

Type-safe Scala 3 contracts compiled to Plutus Core. Property-based testing, in-memory emulator, configurable devnet, formal verification.

Reactive runtime

Event handling, durable workflows, time-based scheduling, transaction submission. Workers that recover cleanly from failure.

Sovereign chain access

JVM-native L1 node embedded in the application or run standalone. No third-party RPC dependency.

Native L2 scaling

Hydrozoa / Gummiworm integration with embedded L1 node. Higher throughput on the same platform, with custom ledger rules.

In one sentence

The thesis

Cardano has shipped the protocol foundations. The next bottleneck is application delivery. Teams still struggle to ship non-trivial applications because they must master and assemble too many moving parts themselves — smart contracts, verification, chain access, operations, scaling.

Scalus is the integrated platform that closes that gap. One coherent stack, one language, one developer experience — from local prototype to production-grade L2-scaled application. Built in Scala 3, native to the JVM ecosystem where roughly 26 million developers and most of finance and fintech already work.

2026 is the window to invest at the application layer.
